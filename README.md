# FieldHub — Field Work Command Center

A mobile-first Progressive Web App designed to manage field work, company visits, travel expenses, follow-ups, and daily work reporting.

## 🚀 Live Demo

**[Open FieldHub](https://bansode2376.github.io/fieldhub/)**

## 📌 Project Overview

FieldHub was built to solve a practical field-work problem: keeping company visit information, client discussions, travel expenses, follow-ups, and daily reporting organized in one place.

The application is designed for use by field sales, business development, service, maintenance, and technical teams.

## ✨ Features

* Company/client visit recording
* Contact person and designation tracking
* Phone and email capture
* Industry and services discussed
* Requirement and visit outcome tracking
* Follow-up date tracking
* GPS location capture
* Travel expense recording
* Daily expense summary
* Visit and expense history
* Daily WhatsApp report generation
* Local data storage
* JSON backup and restore
* Offline functionality
* Installable Progressive Web App
* Responsive mobile-first interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Geolocation API
* Service Worker
* Web App Manifest
* GitHub Pages

## 📱 PWA

FieldHub is designed as a Progressive Web App and can be accessed from a browser or installed on a compatible Android device.

The application uses a service worker to support offline access to the application shell.

## 🎯 Why I Built It

This project was created around a real-world field-work workflow where client visits, requirements, contacts, travel expenses, and daily reporting need to be recorded quickly while working outside the office.
